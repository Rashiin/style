# AIStylist — دموی پرو مجازی محلی

این دمو لباس و اکسسوری را روی عکس مشتری می‌پوشاند. از مدل متن‌باز **Qwen-Image-Edit** (لایسنس Apache 2.0، مجاز برای استفاده تجاری) استفاده می‌کند و روی GPU رایگان Kaggle اجرا می‌شود.
بعد از دانلود مدل‌ها، سرور ساخت تصویر با **اینترنت بسته** کار می‌کند، پس هیچ API خارجی (OpenAI یا هر سرویس دیگری) در کار نیست.

| فایل | کار |
|---|---|
| `demo/kaggle_tryon_demo.ipynb` | نوت‌بوکی که در Kaggle اجرا می‌کنی |
| `demo/tryon_demo.py` | نصب ComfyUI، دانلود مدل‌ها، قطع اینترنت، ساخت تصویر و گزارش |

## اجرا در Kaggle، قدم‌به‌قدم

1. **حساب Kaggle:** در [kaggle.com](https://www.kaggle.com) ثبت‌نام کن و در *Settings → Phone verification* شماره‌ات را تأیید کن. بدون تأیید تلفن، GPU و اینترنت فعال نمی‌شوند.
2. **دیتاست خصوصی عکس‌ها:** *Create → New Dataset*، و **Private** بماند. این فایل‌ها را با همین نام‌ها آپلود کن:
   - `person.png`: عکس تمام‌قد (همان عکسی که کارفرما داده)
   - ست ۱: `blazer.jpg` و `loafers.jpg` (عکس تمیز صفحه محصول، بدون نوشته‌ای مثل «5/8»)
   - ست ۲: `shirt.jpg` (پیراهن سبز) و `trousers.webp` (شلوار مشکی)
   - ست ۳: `jacket.webp` (کت قهوه‌ای) و `bag.webp` (کیف مشکی)
   - پسوند فایل مهم نیست (jpg، png یا webp)، فقط اسم باید همین باشد.
   - اختیاری: `openai_set1.png` تا `openai_set3.png`، خروجی OpenAI کارفرما برای هر ست. اگر باشد، ستون چهارم تصویر مقایسه می‌شود.
3. **ساخت نوت‌بوک:** *Create → New Notebook → File → Import Notebook* و فایل `demo/kaggle_tryon_demo.ipynb` را وارد کن.
4. **تنظیمات نوت‌بوک** (پنل سمت راست):
   - *Accelerator*: **GPU T4 x2**
   - *Internet*: **On** (فقط برای دانلود مدل‌ها لازم است)
   - *Add Input*: همان دیتاستی که در قدم ۲ ساختی
5. **Run All.** بار اول حدود ۲۲ گیگ دانلود می‌شود و ۱۵ تا ۲۵ دقیقه طول می‌کشد. خروجی‌ها در `/kaggle/working/tryon_output` ذخیره می‌شوند (تصویر هر ست، تصویر مقایسه، و `report.md` با زمان هر تصویر و نوع GPU). یک فایل zip هم برای دانلود ساخته می‌شود.

## ضبط ویدیو برای کارفرما

از بخش ۳ نوت‌بوک ضبط را شروع کن. این بخش‌ها باید در ویدیو دیده شوند:
- خط `[offline-guard] active`
- پیام «Request to api.openai.com failed as expected»
- اجرای بخش ۵ و بیرون آمدن تصویر

این‌ها ثابت می‌کنند سرور ساخت تصویر به اینترنت دسترسی ندارد.

## اگر نتیجه خوب نبود

- **ست چندتکه یکجا خوب درنیامد:** در بخش ۴ نوت‌بوک، نسخه دو مرحله‌ای (کت، بعد کفش) را از حالت کامنت دربیاور.
- **کمبود حافظه GPU:** راه‌حلش در بخش Troubleshooting آخر نوت‌بوک است.
- **خطای دیگر:** ۵۰ خط آخر `/tmp/tryon/comfyui.log` را بفرست.

## حریم خصوصی

این ریپو عمومی است. **عکس مشتری، عکس محصولات و خروجی‌ها را هیچ‌وقت اینجا commit نکن.** `.gitignore` جلوی فایل‌های تصویری را می‌گیرد. ورودی‌ها فقط در دیتاست خصوصی Kaggle باشند و بعد از دمو پاک شوند.

## یادداشت فنی

- GPUهای T4 از bf16 پشتیبانی نمی‌کنند، پس ComfyUI با دقت fp32 محاسبه می‌کند. انتظار داشته باش هر تصویر چند دقیقه طول بکشد. روی سرور اصلی با GPU نسل جدید (مثل RTX 4090) و مدل کامل، زمان به چند ثانیه می‌رسد. این را در گزارش به کارفرما صادقانه بنویس.
- نسخه ComfyUI و ComfyUI-GGUF در `tryon_demo.py` ثابت شده تا نصب هر بار یکسان باشد.
